## 📌 Project Overview

The **Global Olympic Sports Performance Analysis** project focuses on analyzing Olympic sports performance, medal achievements, and country-wise participation using data visualization in **Tableau**.

The project transforms Olympic data into meaningful visual insights to understand medal distributions, compare country performances, and explore trends across different Olympic events.

## 🎯 Objectives

- Analyze Olympic medal achievements across countries.
- Compare Gold, Silver, and Bronze medal distributions.
- Identify top-performing countries.
- Explore participation and performance across different sports.
- Analyze Olympic performance trends across different editions.
- Present insights through interactive Tableau dashboards and visualizations.

## 🛠️ Tools & Technologies

- **Tableau Public** — Data visualization and interactive dashboards
- **Microsoft Excel / CSV** — Dataset preparation and data handling
- **Data Visualization** — Charts, graphs, comparisons, and analytical insights

## 📊 Key Features

- **Medal Analysis:** Visual comparison of Gold, Silver, and Bronze medals.
- **Country Performance:** Country-wise medal comparison and rankings.
- **Sports Analysis:** Explore medal distribution across different sports.
- **Participation Analysis:** Understand country and athlete participation.
- **Interactive Dashboards:** Use filters to explore data based on available fields.
- **Performance Trends:** Examine Olympic results across available editions.

## 📈 Project Workflow

1. Collect and prepare the Olympic dataset.
2. Connect the dataset to Tableau.
3. Clean and organize data fields where required.
4. Create charts and visualizations.
5. Combine visualizations into interactive dashboards.
6. Develop a Tableau Story to communicate the findings.
7. Interpret the results and summarize key observations.

## 📂 Dataset

This project uses the **120 Years of Olympic History: Athletes and Results** dataset from Kaggle.

- **Source:** [120 Years of Olympic History — Kaggle](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)
- **Dataset Contents:** Historical Olympic athlete records, participating countries, sports, events, and medal results.
- **Purpose:** To analyze Olympic medal distributions, compare country-wise performance, and explore participation and performance trends across Olympic editions.



## 💡 Expected Outcomes

This project demonstrates how data visualization can simplify complex sports data and help users identify patterns, compare performance, and understand Olympic medal achievements.
